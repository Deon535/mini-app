# План: демо мини-приложения «Исламские книги» для канала @kniga_pdf

## Зачем этот план
Это записанная договорённость: **что** мы строим и **в каком порядке**, кто что делает.
Утвердили → идём по шагам. Перед каждым новым этапом я пишу: «Этап закончен, переходим к следующему».

## Контекст
- Канал @kniga_pdf: 112 904 подписчика, с 2021 года, сотни PDF-книг, 200–320 тыс. просмотров на пост.
  Найти книгу в ленте трудно → нужен удобный каталог и читалка.
- В канале **«Запрет копирования»** → в демо PDF-файлы канала не берём.
- Делаем **демо без владельцев**, чтобы показать им. Пользователь — новичок: всё объясняю по ходу,
  в конце — отчёт «что сделали / что нет».
- Работаем по методичке пользователя: `C:\Users\abusi\разное\дизайн-база\ПАМЯТКА-как-делать-сайты.md`
  и `разбор-вкуса.md` (списки «ВСЕГДА» / «НИКОГДА» обязательны).

## Что будет внутри (утверждаем) — продвинутый вариант
**Главная:** подборки-ленты («Новинки», «Популярное», «С чего начать»), категории с иконками,
блок «Продолжить» (книги с полки).
**Поиск:** мгновенный по названию и автору, без разницы е/ё и регистра, недавние запросы.
**Страница книги:** большая обложка, автор (ссылка на страницу автора), категория, описание;
кнопки «Читать», «На полку», «Поделиться» (ссылка сразу на эту книгу); «Похожие книги».
**Страница автора:** все его книги.
**Моя полка:** «Избранное», «Хочу прочитать», «Прочитано».
**«Читать»:** экран «Полная книга появится здесь в будущем, ин ша Аллах» + кнопка
«Посмотреть, как будет выглядеть чтение» → **наша текстовая читалка** (не PDF) на пробной главе:
арабский — классический матн (общественное достояние), русский — демо-текст, написанный нами.
**Читалка:** темы на выбор вживую (Бумага / Матн / Тёплая ночь / Белая), размер шрифта,
удобный межстрочный и длина строки, арабский книжный шрифт, «где остановился», закладка.
**Интерфейс:** всегда тёплый — днём «бумага», ночью «тёплая ночь» (светлая/тёмная — по Telegram).
**Удобство:** «скелеты» при загрузке, плавные переходы, нормальная работа на слабом интернете.
**Каталог демо:** 20–30 книг — обложка, название, автор, категория, короткое описание.

## Технологии (просто)
- Обычные HTML + CSS + JavaScript, без фреймворков и сборки.
- Экраны внутри одной страницы, адрес меняется после `#` (например `#/book/15`).
- Данные: `books.json` (каталог), `covers/` (обложки, сжатые), `sample-chapter.json` (пробная глава).
- Хостинг: Vercel, подключённый к GitHub (каждый `git push` → сайт обновляется сам).
- Telegram (этап 3): скрипт `telegram-web-app.js` — тема, кнопка «Назад», вибрация,
  полный экран, облако Telegram для полки, ссылка «Поделиться» (`startapp`), «На экран Домой».
  Перед кодом сверяю с актуальной документацией core.telegram.org/bots/webapps.
  Сервер бота и токен в коде **не нужны**; бот в BotFather — нужен (это «дверь» в приложение).

## Этапы и кто что делает

### Этап 1 — Дизайн
- **Я:** `design-system.md` (цвета, шрифты, отступы, компоненты с именами) по методичке.
- **Я:** 4 UI-кита в 4 направлениях — «Книжная лавка», «Классический матн», «Тихий минимал»,
  «Ночная библиотека». В каждом: кнопки, карточка книги, нижнее меню с иконками
  (один набор иконок), страница книги, кусок читалки во всех 4 темах; переключатель между китами.
- **Ты:** открываешь в браузере, выбираешь кит и темы, пишешь правки → я дорабатываю.

### Этап 2 — Сайт (просто в браузере)
- **Ты:** собираешь 20–30 книг из канала (скрин обложки + название, автор, категория, описание).
- **Я:** шаг за шагом пишу экраны (главная → поиск → книга → автор → полка → читалка),
  после каждого объясняю, что и зачем.
- **Ты:** проверяешь в браузере; делаешь `git add / commit / push` (команды даю и объясняю).

### Этап 3 — Telegram
- **Ты:** регистрируешься на Vercel, подключаешь репозиторий → получаешь https-адрес.
- **Ты:** @BotFather → `/newbot` → настраиваешь главное мини-приложение на этот адрес.
- **Я:** подключаю скрипт Telegram и все его возможности (список выше), полка — в облако Telegram
  (вне Telegram — в памяти браузера).
- **Ты:** открываешь бота на телефоне и проверяешь по списку.

### Этап 4 — Доводка и отчёт
- Проверка на телефоне, правки, перечитать все тексты глазами; итоговый отчёт.

## Проверка
- Браузер: все экраны, поиск («намаз», «ё»), полка после перезагрузки, читалка во всех темах.
- Telegram на телефоне: тема светлая/тёмная, «Назад», вибрация, «Поделиться» открывает нужную книгу,
  полка видна на другом устройстве, «На экран Домой».
